# agenthouse engineering 1.8.1

This patch release updates the bundled usability checker so a fresh setup
installs patched transitive dependencies.

- Pins `brace-expansion` 2.1.7, covering CVE-2026-102276, CVE-2026-102277, and
  CVE-2026-102278.
- Pins `fast-uri` 3.1.8, covering CVE-2026-86472.
- Sets usability-runtime overrides so later installs stay on those patched
  ranges. The engineering CLI does not depend on either package.

## Install and update

```text
npm install --global @agenthouse/engineering@1.8.1 --ignore-scripts
```

Existing project runtime pins remain unchanged until explicitly updated.
