# agenthouse engineering 1.12.2

Patch release: heredoc-aware shell expansion handling in the bundled engineering hook runtime.

## Fixes

- Quoted heredoc bodies are treated as literal text during dynamic-expansion checks, so long commit messages containing backticks or `$(...)` examples are not rejected as executable shell expansion.
- Unquoted heredocs remain subject to expansion review.
- Heredoc contents remain visible to Git safety checks, including protected-branch force-push detection.

## Install

Install the exact package version named by this release:

```sh
npm install --global @agenthouse/engineering@1.12.2 --ignore-scripts
```
