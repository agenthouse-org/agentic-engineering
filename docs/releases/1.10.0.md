# agenthouse engineering 1.10.0

This minor release adds a concise recommendation to integrate the latest intended target branch before opening an MR/PR.

- Defines the advisory `git.integrate-target-before-review` rule in the shared lifecycle guidance (ADR-0021).
- Adds reminders to engineer, DevOps, and architect roles, lifecycle and coding-standards skills, and both stack standards.
- Follows project target-branch and merge/rebase conventions, respects existing authorization, and recommends fresh checks after integration.
- Covers already-current branches, ambiguous targets, declined integration, and offline or unverifiable freshness without introducing automatic Git operations or a required gate.

Existing consumer-owned roles use the normal explicit baseline-review and merge process. Project runtime pins remain unchanged until updated.

## Install and update

```text
npm install --global @agenthouse/engineering@1.10.0 --ignore-scripts
```

## Verification

Release preparation runs the automated test suite, generated-skill and release checks, and frozen evaluation. The publication workflow additionally verifies Windows, macOS, Linux, browser behavior, usability, and the packed archive before publishing to npm and attaching an attested update bundle.
