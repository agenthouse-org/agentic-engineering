# agenthouse engineering 1.14.1

Patch release: request host permission review for dynamic shell commands.

## Fixes

- Command substitutions such as file searches no longer receive an unconditional engineering-hook denial. Claude and Cursor shell hooks receive an approval request. Noninteractive hosts may still block when nobody can review.
- Recognized Git policy violations remain denied before the dynamic-command fallback. Unresolved CI review exits 3 and never passes a required check.
- Includes the external-repository edit handling from 1.14.0; the bundled hook export is content-pinned at 0.1.3.

## Install

```sh
npm install --global @agenthouse/engineering@1.14.1 --ignore-scripts
```

Enrolled repositories retain their exact runtime until explicitly updated.

## Verification

The runtime change passed all 204 framework tests, all 8 upstream hook test files, release checks, an isolated demo and CLI hook round trip, frozen evaluation, and Linux/macOS/Windows/browser/usability CI. Release metadata checks are rerun for 1.14.1.
