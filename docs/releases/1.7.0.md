# agenthouse engineering 1.7.0

This minor release discovers installed specialist skills while using roles and
processes.

- `roles show`, `roles use`, `process show`, and `process start` return
  `skillDiscovery` for installed specialist skills whose packaged index or
  SKILL.md frontmatter matches the selected role, process, or stage.
- Includes pinned agenthouse-skills dependencies such as frontend acceptance
  and web usability conformity.
- Reports installed specialist skills with no applicability as unscoped.
- Keeps discovery advisory. It follows the pinned runtime and is not written
  into consumer role or process copies.
- Uses the square agenthouse icon for the Codex dark logo.

## Install and update

```text
npm install --global @agenthouse/engineering@1.7.0 --ignore-scripts
```

Existing project runtime pins remain unchanged until explicitly updated.

## Verification

The generated skill integrity check, release allowlist, complete automated test
suite, and frozen agenthouse evaluation pass for the release commit. The GitHub
release workflow performs cross-platform, browser, usability, package, and npm
publishing checks before publication completes.
