# agenthouse engineering 1.6.0

This minor release strengthens the existing product define stage with an
evidence-traced product requirements workflow for requests that span multiple
stories.

- Adds `ah-define-product-requirements` for defining target users and jobs,
  problems and evidence, outcomes, requirements, constraints, scope, risks,
  story decomposition, and acceptance strategy.
- Keeps customer evidence, assumptions, constraints, and unresolved questions
  visibly distinct throughout the requirements artifact.
- Preserves traceability from evidence to requirements and proposed stories
  with stable local identifiers.
- Routes architecture and implementation choices to
  `ah-assess-tech-feasibility` and does not create work items unless explicitly
  requested.
- Adds "Product requirements and story map" to the existing define-stage
  outputs without introducing a new lifecycle stage.
- Updates the feature-request process and product-manager role to use product
  requirements definition and scope validation for multi-story work.

## Install and update

```text
npm install --global @agenthouse/engineering@1.6.0 --ignore-scripts
```

Existing project runtime pins remain unchanged until explicitly updated.
