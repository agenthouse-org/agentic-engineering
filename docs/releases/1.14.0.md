# agenthouse engineering 1.14.0

Minor release: fix engineering hook handling for dynamic shell commands and edit events outside the enrolled repository.

## Fixes

- Session scratchpad writes from subagents no longer surface as “Edited path outside repository” hook errors.
- Touched-file checks continue to apply to repository files. Symlink edit targets inside the repository remain rejected.
- The pinned `@agenthouse-org/hooks` export is updated to 0.1.3.
- Dynamic shell expansion now requests native host permission review instead of a hard denial. Recognized Git policy violations remain denied; unresolved CI reviews exit 3. Noninteractive hosts may still block pending review.

## Install

```sh
npm install --global @agenthouse/engineering@1.14.0 --ignore-scripts
```
