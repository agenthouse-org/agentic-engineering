# agenthouse engineering 1.8.0

This minor release adds ticket-level test authoring, CI pipeline management,
architecture and coding guideline catalogs, an architect role, and Markdown
discovery help for roles, processes, and command support.

- Adds `test-plan` and `write-tests` with per-criterion levels (including
  interaction), methods (`tdd`, `characterization`, `verify-after`), and
  work-record bindings; see ADR-0017.
- Adds baseline roles `test-manager` and `devops`, plus `pipeline` for
  multi-job GitHub Actions / GitLab CI create, plan, apply, and publish.
- Adds baseline role `architect` with `architecture` and `coding-standards`
  catalog commands linked as `fields.architectureCatalog` and
  `fields.codingStandards`; see ADR-0018.
- Ready gates validate linked test plans and guideline catalogs when those
  fields are present.
- Adds Markdown discovery: `help roles`, `help role ID`, `help processes`,
  `help process ID`, and `help map` for the command × role × process table.

## Install and update

```text
npm install --global @agenthouse/engineering@1.8.0 --ignore-scripts
```

Existing project runtime pins remain unchanged until explicitly updated.
