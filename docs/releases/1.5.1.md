# agenthouse engineering 1.5.1

This patch release completes the public package and plugin presentation for
agenthouse engineering.

- Uses lowercase `agenthouse` branding in published text.
- Identifies Neri GmbH as the package and plugin publisher.
- Links package and plugin listings to `https://agenthouse.org` and the public
  privacy policy.
- Adds discovery keywords, starter prompts, brand color, and implemented plugin
  capabilities.
- Packages the production wordmark, square icons, favicon, and Apple touch icon,
  and references the appropriate assets from the Codex manifest.
- Enrolls this repository in the shared agenthouse lifecycle for Claude, Codex,
  and Cursor with supervised autonomy.

## Install and update

```text
npm install --global @agenthouse/engineering@1.5.1 --ignore-scripts
```

Existing project runtime pins remain unchanged until explicitly updated.

## Verification

The plugin manifest validator, release allowlist and integrity checks, package
dry run, and complete automated test suite pass. The packed archive contains all
five production brand assets.
