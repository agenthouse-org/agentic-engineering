# agenthouse engineering 1.9.1

This patch release makes long Markdown navigable for agents and keeps living
guides version-neutral.

- Documents the overlay convention for short agent-loaded Markdown, on-demand
  references, and section overviews when a file must be long (ADR-0020).
- Adds section overviews to long engine guides under `docs/`.
- Introduces a newest-first [changelog](../CHANGELOG.md); removes release-churn
  lead-ins from living guides so they describe current behavior only.
- Clarifies that the convention is advisory: `doctor` and `evaluate` do not
  enforce Markdown length or overview presence.

## Install and update

```text
npm install --global @agenthouse/engineering@1.9.1 --ignore-scripts
```

Existing project runtime pins remain unchanged until explicitly updated.

## Verification

The generated skill integrity check, release allowlist, complete automated test
suite, and frozen agenthouse evaluation pass for the release commit. The GitHub
release workflow performs cross-platform, browser, usability, package, and npm
publishing checks before publication completes.
