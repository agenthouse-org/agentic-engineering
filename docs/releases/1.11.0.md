# agenthouse engineering 1.11.0

Engineering guidelines now cover architecture, testing, security, Git workflows, delivery, operations, and coding conventions through a broader interface.

- Adds `engineering-guidelines show|check|write` and `ah-engineering-guidelines`.
- Preserves `coding-standards`, its skill, catalog format, work-item fields, and command contracts without migration.
- Fixes catalog writes with a custom `--output` path so the status report no longer overwrites the catalog, for both command names.
- Adds shared agent and lifecycle guidance to assess applicable rules before planning or changing something, reuse current context and authorization, and ask only about conflicts, missing material decisions, or exceptions requiring approval.
- Exposes the skill through engineering roles, relevant processes, and discovery help.
- Keeps catalog validation, compliance assessment, automated checks, and governance approval distinct; no automatic pre-action gate is introduced.

Existing consumer-owned roles and processes retain explicit baseline review and merge. Project runtime pins remain unchanged until updated.

## Install and update

```text
npm install --global @agenthouse/engineering@1.11.0 --ignore-scripts
```

## Verification

Release preparation covers alias interoperability, failure paths, non-mutating catalog checks, discovery, the automated suite, generated-skill/release checks, and frozen evaluation. The publication workflow verifies Windows, macOS, Linux, browser behavior, usability, and the packed archive before publishing npm and attaching an attested update bundle.
