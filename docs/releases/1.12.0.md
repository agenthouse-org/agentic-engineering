# agenthouse engineering 1.12.0

This release makes review and verification guidance more explicit while keeping test selection proportionate to the changed behavior.

- Adds consumer-owned governance guidance for reviews where the author is unavailable, including an explicit unresolved-decision signal when no local procedure exists.
- Routes changed browser journeys to the configured Playwright or end-to-end runner, visual criteria to `frontend-acceptance`, and changed system boundaries to planned integration-test evidence.
- Adds criterion-linked test planning and planned-test-level verification to the feature, bug, change, and product lifecycle process guidance.
- Refreshes the generated skills, hook runtime bundle, policy schema, and enrolled runtime artifacts for the current framework version.

Existing consumer-owned roles and processes retain explicit baseline review and merge. The new process wording is advisory and does not make any particular test type mandatory for unrelated work.

## Install and update

```text
npm install --global @agenthouse/engineering@1.12.0 --ignore-scripts
```
