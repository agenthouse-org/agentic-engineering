# agenthouse engineering 1.12.1

This patch release lets organization policy define repository branch naming while preserving existing project configuration behavior.

- Adds the `branch-naming` policy rule with `default` and `mandatory` modes.
- Validates policy patterns during resolution and records project/policy provenance.
- Uses resolved policy in onboarding, doctor, and work-branch creation.
- Documents that `{id}` is the local work-item id and updates branch-naming guidance.

Projects without a `branch-naming` policy rule retain their existing behavior.

## Install and update

```text
npm install --global @agenthouse/engineering@1.12.1 --ignore-scripts
```

## Verification

The release checks cover policy precedence, mandatory conflicts, base-branch overrides, unsafe patterns, onboarding guidance, and organization-controlled work branches.
